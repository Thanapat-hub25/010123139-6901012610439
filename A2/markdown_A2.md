## 4. OOP (Object-Oriented Programming)

* Class ที่ใช้:

  1. `BaseProduct`: คลาสแม่สำหรับเก็บข้อมูลพื้นฐานของสินค้า

  2. `Product`: คลาสลูกที่สืบทอดมาจาก `BaseProduct` เพื่อจัดการข้อมูลจำนวนสินค้าในสต็อก

  3. `Inventory`: คลาสผู้จัดการคลังสินค้า สำหรับควบคุมเมนูและการทำงานทั้งหมด

* หน้าที่ของ class:

  * `BaseProduct`: เก็บและแสดงผลข้อมูลพื้นฐานสินค้า (รหัส, ชื่อ, ราคา)

  * `Product`: ต่อยอดจากคลาสแม่เพื่อแสดงจำนวนสินค้าคงเหลือ (ใช้นวัตกรรม Inheritance และ Method Overriding)

  * `Inventory`: ทำหน้าที่ประมวลผลข้อมูลในคลังสินค้า บันทึก/อ่านไฟล์ `inventory.txt` และรับคำสั่งจากผู้ใช้งาน

* ตัวแปร (attribute):

  * `BaseProduct`: `product_id` (ข้อความ), `name` (ข้อความ), `price` (ตัวเลขทศนิยม)

  * `Product`: `stock` (ตัวเลขจำนวนเต็ม)

  * `Inventory`: `products_data` (List 2 มิติสำหรับเก็บข้อมูลสินค้า), `filename` (ชื่อไฟล์ข้อความ `inventory.txt`)

* เมธอด (method):

  * `BaseProduct.display_info()`: แสดงรหัส ชื่อ และราคาสินค้า

  * `Product.display_info()`: เขียนทับเมธอดเดิม (Overriding) เพื่อแสดงจำนวนสินค้าในสต็อกเพิ่ม

  * `Inventory._load_from_file()`: อ่านข้อมูลจากไฟล์มาเก็บใน List 2 มิติ

  * `Inventory._save_to_file()`: เขียนข้อมูลจาก List 2 มิติกลับลงไฟล์

  * `Inventory.add_product()`: รับข้อมูลสินค้าใหม่ และเช็กไม่ให้กรอกข้อมูลซ้ำหรือผิดรูปแบบ

  * `Inventory.show_product()`: ดึงข้อมูลจาก List มาสร้างเป็น Object สินค้าแล้วแสดงผล

  * `Inventory.search_product()`: ค้นหาสินค้าตามรหัสที่ระบุ

  * `Inventory.stock_in()`: เพิ่มจำนวนสินค้าเข้าสต็อก

  * `Inventory.stock_out()`: ตัดสต็อกเมื่อขายสินค้าพร้อมคำนวณราคารวม

  * `Inventory.low_stock()`: แสดงรายการสินค้าที่เหลือไม่เกิน 5 ชิ้น

* ตัวอย่างโค้ด:

```
# คลาสแม่เก็บข้อมูลพื้นฐาน
class BaseProduct:
    def __init__(self, product_id, name, price):
        self.product_id = str(product_id)
        self.name = str(name)
        self.price = float(price)

    def display_info(self):
        print(f"รหัสสินค้า : {self.product_id}")
        print(f"ชื่อสินค้า : {self.name}")
        print(f"ราคา       : {self.price:.2f} บาท")

# คลาสลูกสืบทอดคุณสมบัติจากคลาสแม่
class Product(BaseProduct):
    def __init__(self, product_id, name, price, stock):
        super().__init__(product_id, name, price)
        self.stock = int(stock)

    def display_info(self):
        super().display_info()
        print(f"จำนวน      : {self.stock} ชิ้น")

```

## 5. Array

* ใช้ array เก็บข้อมูลอะไร: ใช้ List 2 มิติ (`products_data`) เก็บข้อมูลสินค้าเป็นแถวและคอลัมน์ ในรูปแบบ `[[รหัส, ชื่อ, ราคา, จำนวน], ...]`

* ขนาดและชนิดข้อมูล: เป็น Dynamic Array (ขยายขนาดได้ตามต้องการ) โดยแต่ละตำแหน่งในแถวเก็บข้อมูลชนิดต่างกัน:

  * ช่องที่ 0 (`[0]`): รหัสสินค้า (ข้อความ `str`)

  * ช่องที่ 1 (`[1]`): ชื่อสินค้า (ข้อความ `str`)

  * ช่องที่ 2 (`[2]`): ราคาสินค้า (ทศนิยม `float`)

  * ช่องที่ 3 (`[3]`): จำนวนคงเหลือ (จำนวนเต็ม `int`)

* ตัวอย่างโค้ด:

```
# สร้าง List เปล่าสำหรับเก็บข้อมูลสินค้าหลายๆ รายการ (List 2 มิติ)
self.products_data = []

# เพิ่มแถวข้อมูลสินค้าเข้า List
self.products_data.append([product_id, name, price, stock])

# เข้าถึงและอัปเดตข้อมูลจำนวนสินค้าที่ index 3 ใน List 2 มิติ
for row in self.products_data:
    if row[0] == search:
        row[3] += amount  # เพิ่มจำนวนในช่องสต็อก

```
